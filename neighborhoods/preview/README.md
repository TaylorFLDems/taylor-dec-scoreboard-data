# Neighborhood scoreboard preview

Test build of the Perry neighborhood turnout scoreboard and its social post.

- `index.html`: the scoreboard page with the interactive map
- `social.html`: the 1080 x 1350 social post

**Sample numbers only.** Every percentage here is made up for layout testing.
The map holds neighborhood outlines only: no parcels, no lots, no voter data.
Pages carry `noindex` so search engines skip them.

Built from the Claude Design canvas "Neighborhood Turnout Preview".

`live.html` (Oct 23): the exact Solidarity Tech block, wrapped in a bare page, reading the real
`neighborhoods.json` from `main`. Percentages only. For testing on a phone before the site page goes up.
